The Redmi Note 10S (codenamed _"rosemary"_) is a mid-range smartphone from Xiaomi.

It was announced in March 2021.


| Basic                   | Spec Sheet                                                                                                                     |
| -----------------------:|:------------------------------------------------------------------------------------------------------------------------------ |
| CPU                     | Octa-core (2x2.05 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)                                                                       |
| Chipset                 | Mediatek MT6785V/CD Helio G95 (12 nm)                                                                                          |
| GPU                     | Mali-G76 MC4                                                                                                                   |
| Memory                  | 4/6/8 GB RAM (LPDDR4X)                                                                                                         |
| Shipped Android Version | 11.0                                                                                                                           |
| Storage                 | 64/128 GB (UFS 2.2)                                                                                                            |
| Battery                 | Non-removable Li-Po 5000 mAh                                                                                                   |
| Display                 | 1080 x 2400 pixels, 20:9 ratio (~409 ppi density)                                                                              |
| Camera (Back)(Main)     | 64MP + 8MP + 2MP + 2MP                                                                                                         |
| Camera (Front)          | 13MP                                                                                                                           |
